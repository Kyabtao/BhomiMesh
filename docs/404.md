# 404 — Page Not Found

**URL:** `http://localhost:8080/404.html` (automatic for any unknown path on most static hosts)

## Purpose
Graceful dead-end page for the deploy-ready static site: consistent dark slate theme, brand header
with a "Back to Home" shortcut, and three recovery links (Home, Documents, Roadmap).

## Structure
| Block | Notes |
|---|---|
| `<nav>` | Static (no `partials.js` — 404 must work with zero JS dependency) |
| Error badge + headline | "Error 404 / Plot not found" |
| Recovery grid | `index.html`, `documents.html`, `roadmap.html` cards |
| `<footer>` | Links to `docs/README.md` |

## Notes
- Fully static: Tailwind CDN + FontAwesome, no `assets/js` scripts beyond the shared
  `tailwind.config.js`, so the page renders even if the JS assets fail.
- Keep the three recovery links in sync if the core pages are renamed.
